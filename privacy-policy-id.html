1. Tentang Kami

Neraca ("Aplikasi") adalah aplikasi manajemen keuangan pribadi yang dikembangkan oleh Dalvero ("kami"). Kebijakan Privasi ini menjelaskan informasi apa yang dikumpulkan Aplikasi, bagaimana data digunakan, disimpan, dan dibagikan, serta pilihan yang Anda miliki. Kebijakan ini berlaku untuk aplikasi mobile maupun situs web ini.

Neraca dirancang sebagai alat pribadi untuk satu pengguna: catatan keuangan Anda adalah milik Anda, dan kami tidak pernah menjual, menyewakan, atau memonetisasi data Anda dengan cara apa pun.

2. Data yang Kami Kumpulkan

2.1 Informasi Akun

Saat Anda masuk, kami menerima:

  • Google Sign-In: alamat email, nama tampilan, dan foto profil sebagaimana diizinkan layar persetujuan OAuth Google.
  • Email & Kata Sandi: alamat email dan kata sandi terenkripsi (ditangani Firebase Authentication; kata sandi tidak pernah terlihat oleh kami).
  • ID Pengguna: identifikasi internal (Firebase UID atau identitas tamu lokal) yang dipartisi per pengguna di perangkat.

2.2 Data Keuangan

  • Transaksi (pemasukan, pengeluaran, transfer), saldo dompet (Kas Harian dan Tabungan Impian), anggaran kategori, dan target tabungan.
  • Data ini disimpan lokal di perangkat Anda menggunakan Android SharedPreferences, dikunci berdasarkan ID pengguna.
  • Jika Anda mengaktifkan sinkronisasi Google Sheets, data yang sama ditulis ke Google Spreadsheet milik Anda sendiri (lihat Bagian 4). Kami tidak pernah menerima salinannya di server kami — untuk fitur ini kami tidak memiliki server.

2.3 Konten AI (Acha AI)

  • Teksten yang Anda ketik ke asisten Acha AI (misalnya catatan belanja atau pertanyaan seputar keuangan).
  • Gambar yang Anda proses — foto struk kasir atau tangkapan layar mutasi bank yang Anda ambil melalui kamera atau galeri.
  • Input ini dikirim ke Google Gemini API untuk pemrosesan bahasa alami dan OCR. Riwayat percakapan disimpan lokal di perangkat, dikunci berdasarkan ID pengguna.

2.4 Foto Profil

Jika Anda mengunggah foto profil, gambar tersebut dikirim ke Cloudinary (unggahan tanpa tanda tangan/unsigned) dan URL-nya disimpan di profil lokal Anda.

2.5 Data yang TIDAK Kami Kumpulkan

  • Tidak ada lokasi presisi, kontak, atau akses mikrofon.
  • Tidak ada identifikasi iklan dan tidak ada SDK analytics pihak ketiga.
  • Tidak ada kredensial bank — Neraca tidak pernah meminta atau menyimpan login perbankan Anda.
  • Isi notifikasi dibuat dan ditampilkan hanya di perangkat Anda (peringatan anggaran, pengingat).

3. Bagaimana Data Digunakan

  • Menyediakan fitur inti: mencatat transaksi, menghitung saldo, transfer antar dompet, dan pelacakan anggaran.
  • Menyinkronkan pembukuan ke Google Spreadsheet milik Anda saat Anda secara eksplisit menautkannya.
  • Memproses teks dan gambar yang Anda kirimkan ke Acha AI agar dapat memecah transaksi, membaca struk, dan menjawab pertanyaan keuangan.
  • Mempertahankan sesi login Anda dan memulihkan data saat berganti akun di perangkat yang sama.
  • Menampilkan notifikasi lokal untuk peringatan anggaran (ambang 80% / 100%) dan pengingat target tabungan.

Batasan tujuan: data Anda hanya digunakan untuk menjalankan fitur Aplikasi untuk Anda. Kami tidak menggunakannya untuk periklanan, profil, atau pengambilan keputusan otomatis.

4. Layanan Pihak Ketiga

Aplikasi bergantung pada penyedia berikut. Masing-masing memproses data di bawah kebijakan privasinya sendiri:

Layanan Tujuan Data yang Terlibat
Firebase Authentication (Google) Login via Google, email/sandi, dan sesi anonim Email, nama, foto profil, ID pengguna
Google Sheets API Sinkronisasi dua arah pembukuan ke spreadsheet Anda sendiri Transaksi, anggaran, saldo dompet (hanya saat ditautkan)
Google Drive API Menelusuri dan membuat file spreadsheet Anda Metadata file spreadsheet (hanya saat ditautkan)
Google Gemini API Pemrosesan transaksi bahasa alami dan OCR struk/mutasi Teks dan gambar yang Anda kirim ke Acha AI
Cloudinary Hosting foto profil Foto profil yang Anda unggah
Google Fonts (hanya situs web ini) Menampilkan tipografi Plus Jakarta Sans Alamat IP (diminta dari CDN Google)

Tautan: Kebijakan Privasi Google · Privasi Firebase · Kebijakan Privasi Cloudinary

5. Penyimpanan & Keamanan Data

  • Local-first: data keuangan tersimpan di penyimpanan perangkat (SharedPreferences) dan dipartisikan per ID pengguna (transaksi dikunci per akun), sehingga beberapa akun atau tamu di satu perangkat tidak pernah tercampur.
  • Spreadsheet milik Anda: jika sinkronisasi aktif, data berlangsung langsung dari perangkat ke akun Google Anda sendiri. Kami tidak dapat membacanya.
  • Transportasi: seluruh lalu lintas API menggunakan TLS/HTTPS.
  • Sesi: status login disimpan lokal di perangkat; keluar (logout) kapan saja untuk mengakhiri sesi aktif.

6. Mode Tamu

Anda dapat memakai Neraca tanpa akun. Pada Mode Tamu, Aplikasi lebih dulu mencoba Firebase Anonymous Authentication; jika offline, beralih ke sesi tamu lokal murni. Google Drive, Google Sheets, dan seluruh sinkronisasi latar belakang diblokir keras pada Mode Tamu — data keuangan tamu tidak pernah meninggalkan perangkat.

7. Hak Anda & Penghapusan Data

Anda memegang kendali atas data Anda. Anda dapat:

  1. Menghapus spreadsheet Anda: karena sinkronisasi menulis ke Google Spreadsheet milik Anda sendiri, Anda dapat mengedit atau menghapusnya langsung di Google Sheets/Drive kapan saja.
  2. Menghapus data lokal: hapus data Aplikasi melalui Pengaturan Android → Aplikasi → Neraca → Hapus Penyimpanan, atau dengan mencopot pemasangan Aplikasi.
  3. Keluar (logout): gunakan tombol Keluar di Aplikasi untuk mengakhiri sesi dan menghapus status sesi aktif.
  4. Minta penghapusan akun: hubungi kami di alamat pada Bagian 10 dan kami akan menghapus akun Firebase serta data yang dapat kami kaitkan dengan Anda.

Di mana GDPR atau hukum serupa berlaku, Anda juga dapat meminta akses, koreksi, atau salinan data pribadi Anda, serta menolak atau membatasi pemrosesan tertentu.

8. Privasi Anak

Neraca adalah alat keuangan pribadi untuk audiens umum. Aplikasi tidak ditujukan bagi anak-anak di bawah 13 tahun (atau usia minimum di wilayah Anda), dan kami tidak sengaja mengumpulkan informasi pribadi dari anak-anak. Jika Anda yakin seorang anak telah memberikan data kepada kami, hubungi kami dan kami akan menghapusnya.

9. Perubahan Kebijakan Ini

Kami dapat memperbarui Kebijakan Privasi ini untuk mencerminkan perubahan pada Aplikasi atau hukum yang berlaku. Tanggal "Terakhir diperbarui" di bagian atas halaman ini akan berubah saat ada penyuntingan. Penggunaan Aplikasi yang berlanjut setelah perubahan merupakan persetujuan terhadap kebijakan yang direvisi.
